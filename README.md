# KuhlFamily

Starter für die gemeinsame Haushalts- und Familien-App.

Bereits enthalten: Benutzerwahl Dominic/Sabrina/Familie, warmes Familien-Design mit dem KuhlMoments-Foto, Dashboard, Aufgaben, Einkauf, häufig gekauft, Kalender, Maps-Link, Schnell-Plus, Pinnwand, Ausgaben-Grundlage, PWA und Firebase-Grundanschluss.

Ohne Firebase läuft die App zunächst lokal als Demo. Nach Eintragen von `firebase-config.js` werden die Daten über Firestore geteilt.

Siehe `ANLEITUNG.md`.
